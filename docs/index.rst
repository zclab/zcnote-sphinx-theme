功能测试：两端对齐
==================

这里是一段非常长的测试文本。为了验证正文段落是否能够正确地实现两端对齐（text-align: justify），
我们需要输入足够多的文字。在传统的网页排版中，如果不设置两端对齐，段落的右侧通常会显得参差不齐。
